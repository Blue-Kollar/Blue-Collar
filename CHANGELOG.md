## [Unreleased]

### Removed

- **api:** Legacy deprecated authentication endpoints (`enrollTwoFactor`,
  `verifyTwoFactor`, `disableTwoFactor` in `controllers/auth.ts`; old device
  handlers `listDevices`, `revokeDevice`, `revokeAllOtherDevices` that
  previously lived in the auth controller) were already removed in #1012 and
  are now confirmed absent. All active 2FA routes live in
  `controllers/twoFactor.ts`; device routes live in `controllers/devices.ts`.
  This closes the attack surface documented in issue #1216. (#1216)

### Fixed

- **api:** Wrapped all previously bare `async function` controller handlers
  in `catchAsync` so unhandled promise rejections propagate to the global
  `errorHandler` middleware instead of crashing the process. Affected
  controllers: `admin-users.controller.ts`, `export.ts`, `helpful.ts`,
  `admin-stats.controller.ts`, `admin-audit.controller.ts`. All error
  responses now consistently return
  `{ status, message, code, errorCode, traceId }`. (#1215)

### Performance

- **api:** Confirmed no N+1 queries in listing endpoints. `EscrowRepository`
  `listEscrows` uses `Promise.all([findMany, count])`. `notifications`
  controller uses `Promise.all([findMany, count])`. Worker export uses a
  single Prisma `include` (joined query). Added regression tests to prevent
  future regressions. (#1217)

### Chore

- **api:** Completed Prisma schema audit — all models are actively referenced
  by application code; no orphaned models or stale migrations found. Added
  schema audit regression tests. (#1218)

## [1.0.0] - 2026-03-29

### Features

- **api:** JWT authentication with email verification and password reset
- **api:** Google OAuth 2.0 login via Passport
- **api:** Role-based access control (`user`, `curator`, `admin`)
- **api:** Worker CRUD with curator-gated listings
- **api:** Profile image uploads with Multer and Sharp (method-override for multipart PUT)
- **api:** Category management with seed data
- **api:** Admin endpoints for user and worker management
- **api:** Rate limiting, CORS, and Helmet security headers
- **api:** Pino structured logging
- **api:** Prisma ORM with PostgreSQL (User, Worker, Category, Location models)
- **api:** Nodemailer email transport with HTML templates
- **contracts:** Registry Soroban contract — curator-gated worker registration, toggle, update, deregister
- **contracts:** Market Soroban contract — direct tips and time-locked escrow payments
- **contracts:** Protocol fee (max 5%) with configurable fee recipient
- **contracts:** On-chain privacy via SHA-256 hashed location and contact fields
- **contracts:** Automatic storage TTL extension (~1 year) on every write
- **contracts:** In-place WASM upgrade support for both contracts
- **app:** Next.js 14 frontend scaffold with Tailwind CSS and shadcn/ui
- **ci:** GitHub Actions workflows for API tests, contract build/clippy, and app lint/build
